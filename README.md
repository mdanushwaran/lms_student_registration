### LMS Portal – Registration Page

The **Registration Page** allows new students/users to create an account in the Learning Management System.

**Fields:**

1. Full Name
2. Email Address
3. Mobile Number
4. Username
5. Password
6. Confirm Password
7. Course / Department
8. Gender
9. Date of Birth
10. Address
11. Profile Photo
12. **Register** button
13. **Already have an account? Login** link

**Basic flow:**

`Registration Form → Validate Details → Store User Data → Registration Successful → Login Page`
